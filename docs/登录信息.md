# 教育智能体测试1 登录信息

## 本地访问地址

开发服务地址：

- 本机：`http://localhost:3000`
- 局域网：`http://192.168.50.40:3000`

## 前端登录与入口

- 教师登录页：`http://localhost:3000/teacher/login`
- 教师注册页：`http://localhost:3000/teacher/register`
- 学生登录页：`http://localhost:3000/student/login`
- 学生注册页：`http://localhost:3000/student/register`
- 教师后台：`http://localhost:3000/teacher`
- 学生 iPad 端：`http://localhost:3000/student`
- 大屏展示页：`http://localhost:3000/display/[taskId]`

`[taskId]` 需要替换成教师创建任务后生成的任务 ID，并且该任务需要开启大屏展示。

## 后端登录接口

本项目后端 API：

- 注册并同步智美底座：`POST http://localhost:3000/api/auth/register`
- 本地账号密码登录：`POST http://localhost:3000/api/auth/login`
- 拉取底座班级适配接口：`GET http://localhost:3000/api/base/classes`
- 教师创建/查看任务：`GET/POST http://localhost:3000/api/tasks`
- 学生提交作品：`POST http://localhost:3000/api/submissions`
- 大屏读取展示作品：`GET http://localhost:3000/api/display/tasks/[taskId]`

智美教育业务底座文档：

- API 文档：`http://meiyu.cdbbox.com/api/docs`
- 平台登录：`POST {BASE_API_URL}/api/v1/auth/login`
- 平台刷新 token：`POST {BASE_API_URL}/api/v1/auth/refresh`
- 应用授权：`GET {BASE_API_URL}/api/v1/auth/authorize`
- 授权码换 token：`POST {BASE_API_URL}/api/v1/auth/token`
- 当前用户上下文：`GET {BASE_API_URL}/api/v1/auth/me`
- 本地用户同步到底座：`POST {BASE_API_URL}/api/v1/app-auth/users/sync`
- 查看当前智能体同步用户：`GET {BASE_API_URL}/api/v1/applications/{appId}/users?agentName={BASE_AGENT_NAME}`

## 管理员/教师账号

当前项目没有内置默认管理员账号或默认密码。

首版系统只有两类业务角色：

- `TEACHER`：教师后台用户，相当于本项目的管理使用者
- `STUDENT`：学生用户

创建教师账号：

1. 打开 `http://localhost:3000/teacher/register`
2. 填写邮箱、用户名、显示名称和密码
3. 注册成功后进入 `http://localhost:3000/teacher`

注意：教师注册会调用智美底座同步接口，需要 `.env` 中配置真实值：

```bash
BASE_API_URL="http://meiyu.cdbbox.com"
BASE_APP_ID="你的应用ID"
BASE_APP_SECRET="你的应用密钥"
BASE_AGENT_NAME="教育智能体测试1"
```

如果底座同步失败，注册会失败，不会保留半绑定账号。

## 学生账号

学生账号注册：

1. 打开 `http://localhost:3000/student/register`
2. 填写学生姓名、邮箱、密码和年龄段
3. 注册后进入 `http://localhost:3000/student`

学生登录页同样是：

`http://localhost:3000/student/login`

## 环境变量
